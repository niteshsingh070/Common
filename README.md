# 💌 Ask Her Out — Cute Date Invitation Website

A playful multi-round page. She can only say YES (the "No" button runs away or turns into "Yes"),
then she picks a date, time and activity, and sends the answer to you on WhatsApp.

## 1. Customize
Open **config.js** and change your name, number, questions, activities and colors.

## 2. Run on your computer
Just double-click **index.html**. (Or run `python -m http.server 8000` in this folder
and open http://localhost:8000)

## 3. Host free on GitHub Pages
1. Create a new GitHub repository (e.g. `ask-me-out`) and upload all files in this folder.
2. Go to **Settings → Pages**.
3. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, Save.
4. After about a minute your link is: `https://YOUR-USERNAME.github.io/ask-me-out/`

## 4. One link per person
Add her name to the link, no code edit needed:

    https://YOUR-USERNAME.github.io/ask-me-out/?to=Sara
    https://YOUR-USERNAME.github.io/ask-me-out/?to=Priya&from=Raj

Optional: `&wa=91XXXXXXXXXX` to send the answer to a different WhatsApp number.
